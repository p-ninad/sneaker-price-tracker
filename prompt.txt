=========================================
SCRAPING STRATEGY
=========================================

For EACH platform:

Step 1:
Attempt to identify hidden APIs.

The collector should first try:

- JSON APIs
- GraphQL APIs
- internal search endpoints
- catalog endpoints
- listing endpoints

Inspect browser network requests.

If APIs exist:

Use APIs instead of HTML scraping.

Benefits:
- faster
- structured
- more stable
- less anti-bot risk

Step 2:
Fallback to Playwright rendering.

If no usable API exists:

Use Playwright headless Chromium.

Then parse rendered HTML using BeautifulSoup.

DO NOT rely purely on CSS selectors without fallback strategies.

Selectors should be configurable.
