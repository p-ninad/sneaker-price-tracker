================================================================================
                              SETUP INSTRUCTIONS
================================================================================

Quick Start (5 minutes):

1. Get Telegram Bot Token
   - Chat with @BotFather on Telegram
   - Create new bot
   - Save token (e.g., 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11)

2. Get Your Chat ID
   - Run: curl https://api.telegram.org/bot{TOKEN}/getUpdates
   - Message the bot first, then run the command
   - Find "chat": {"id": 123456789}

3. Update .env
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
   TELEGRAM_CHAT_ID=123456789

4. Verify Tests Pass
   cd price_tracker
   source venv/bin/activate
   pytest src/tests/unit/test_notifier.py -v

5. Deploy
   make docker-build
   make docker-run

Done! Your tracker will now send Telegram notifications.
