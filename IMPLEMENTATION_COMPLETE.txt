================================================================================
                              HOW TO USE
================================================================================

From Collector → TrackingService:

    from app.services.tracking import TrackingService
    from app.database.repository import ProductRepository

    service = TrackingService()

    # After collector finds a product and stores it:
    analysis = service.analyze_product_update(
        session,
        product=existing_product,
        new_listed_price=7999.0,
        new_discounted_price=6999.0,
        new_discount_percentage=12.5,
        new_in_stock=True,
        new_sizes_available='["6","7","8","9"]'
    )

    if analysis.has_changes():
        alerts = service.create_alerts_from_analysis(session, analysis)
        # Alerts created, ready for notification

    # Record history for trends
    service.record_price_snapshot(session, product, ...)
    service.record_stock_snapshot(session, product, ...)

    # Get 30-day trend
    trend = service.get_price_trend(session, product.id, days=30)
    # Returns: {snapshots, min_price, max_price, current, change_percent}

See: INTEGRATION_EXAMPLES.py for complete examples

================================================================================
                              CONFIGURATION
================================================================================

Edit .env to customize:

  PRICE_DROP_THRESHOLD_PERCENT=10
    → Only alert if price drops more than 10%

  NEW_PRODUCT_NOTIFICATION_ENABLED=true
    → Alert when new products discovered

  RESTOCK_NOTIFICATION_ENABLED=true
    → Alert when out-of-stock items return

Database:
  DATABASE_URL=sqlite:////path/to/data/price_tracker.db

Logging:
  LOG_LEVEL=INFO  # Options: DEBUG, INFO, WARNING, ERROR
